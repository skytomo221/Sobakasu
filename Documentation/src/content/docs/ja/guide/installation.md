## VPM repositoryを追加する

VRChat Creator Companion (VCC) またはALCOMで、次のrepository URLを追加します。

```text
https://skytomo221.com/Sobakasu/index.json
```

このURLはVPMのmachine-readable listingです。VCCへ登録済みの場合は、URLを変更・再登録する必要はありません。

## Sobakasuパッケージを追加する

対象のWorldsプロジェクトでSobakasuパッケージを追加します。使用するプロジェクトにはUnity 2022.3.22f1とVRChat Worlds SDK 3.10.4以上が必要です。

追加後は[Getting Started](../getting-started/)に進んでください。
